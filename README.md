# 🛡️ TrustCheck AI — Digital Trust Guardian

### Detect. Investigate. Protect. Recover.

**TrustCheck AI** is an AI-powered fraud-risk intelligence platform designed to help students, job seekers, and internet users identify potentially fraudulent scholarships, internships, job offers, recruitment messages, and online opportunities.

Powered by **Google Gemini**, the platform focuses on explainable analysis, evidence-based risk assessment, independent verification, and practical online safety.

## 🎯 Problem Statement

Fake job offers, fraudulent scholarship advertisements, phishing messages, and recruiter impersonation put people at risk of financial loss, identity theft, and exposure of personal information.

Traditional detection methods may flag suspicious content without explaining the underlying evidence.

## 💡 Our Solution

TrustCheck AI is designed to transform suspicious messages and documents into understandable risk assessments.

The platform aims to help users:

- Identify suspicious language and requests.
- Understand the evidence behind warnings.
- Investigate potential organizational impersonation.
- Verify claims using reliable official sources.
- Protect sensitive personal information.
- Make safer decisions before responding or applying.

## 🚀 Key Capabilities

**AI-Powered Offer Analysis**

Analyze suspicious job advertisements, scholarship announcements, internship offers, and recruitment messages.

**Explainable Risk Intelligence**

Identify warning signs such as unusual payments, artificial urgency, suspicious links, and credential requests.

**Multimodal Intelligence**

Support analysis of screenshots, documents, and other supported formats as these capabilities are implemented.

**Independent Verification**

Compare relevant claims against publicly available sources when external verification is configured.

**Privacy & Digital Safety**

Help users recognize sensitive-information requests and understand appropriate protective actions.

## ⚙️ Getting Started

1. Clone or download this repository.
2. Install dependencies using `npm install`, if supported by the project's package configuration.
3. Configure the Gemini API key securely on the server side.
4. Run the development script defined in `package.json`, commonly `npm run dev`.
5. Open the development URL shown in the terminal.

Never publish API credentials in the repository.

## 🌍 Who Can Benefit?

TrustCheck AI is designed for students, scholarship applicants, internship seekers, graduates, job seekers, and anyone evaluating unfamiliar online opportunities.

## 🔐 Responsible AI

TrustCheck AI provides automated risk assessments, not guaranteed fraud detection. Its findings should be interpreted alongside independent verification and credible official sources.
